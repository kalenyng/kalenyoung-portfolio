High H2 — No security headers (vercel.json missing entirely) ▼

No Content-Security-Policy, no X-Frame-Options, no X-Content-Type-Options, no HSTS declaration, no Referrer-Policy. HTTPS transport is correct (Vercel handles it) but all response-header security signals are absent.

FixCreate vercel.json at repo root:
{
  "headers": [
    {
      "source": "/(.*)",
      "headers": [
        { "key": "X-Content-Type-Options", "value": "nosniff" },
        { "key": "X-Frame-Options", "value": "SAMEORIGIN" },
        { "key": "Referrer-Policy", "value": "strict-origin-when-cross-origin" },
        { "key": "Strict-Transport-Security", "value": "max-age=31536000; includeSubDomains" },
        { "key": "Permissions-Policy", "value": "camera=(), microphone=(), geolocation=()" }
      ]
    }
  ]
}
High H3 — LCP deferred by preloader (~1.4–2s delay) ▼

On first visit, the preloader hides all [data-hero-line] elements with opacity: 0; visibility: hidden and only reveals them after the Three.js .glb model loads + GSAP animation completes (~1.4–2s). This pushes LCP into the "Needs Improvement" or "Poor" band.

Fix (quick)Add fetchpriority="high" to the Propza cover preload link in BaseLayout.astro:159.
